# KKit — notes for Claude

KKit is a native macOS utility app (Swift 6, SwiftUI + AppKit, macOS 14.2+), distributed
outside the App Store. Read these before changing anything:

- `docs/DESIGN.md` — product and UI/UX design of every feature
- `docs/ARCHITECTURE.md` — modules, the `Feature` protocol, hosts, services, conventions
- `docs/ROADMAP.md` — build order

## Rules

- Features are plug-ins in `Packages/KKitModules/Sources/Features/Feature<Name>/`. They
  depend only on `KKitCore`, `KKitUI`, `KKitServicesAPI`. **Never import one feature from
  another**; share through a protocol in `KKitServicesAPI` (`services.publish/resolve`) or
  an `AppEvent`.
- Features never create their own windows, panels or event taps. Use `OverlayService`,
  the Island/Floating Bar hosts, and `InputTapService`.
- Every user action is a `Command` with id `<featureID>.<verb>`. Don't add hotkeys, menu
  items or URL handlers separately; the command system generates them.
- Private/fragile macOS APIs live only inside a service implementation in `KKitServices`,
  loaded dynamically, with a fallback or an "unavailable" state.
- `@MainActor` for features, hosts and views; heavy work in actors. Nothing samples or
  polls unless something visible needs it.
- The `.xcodeproj` is generated by XcodeGen from `project.yml`. Edit `project.yml`, never
  the project file.

## Adding a feature

Follow `docs/ARCHITECTURE.md` §11: create the target, implement `Feature`, register it in
`App/FeatureCatalog.swift`, add a README in the feature folder, add a row to the table in
§10, add tests.

## Building

This repo can't be built on Linux. CI (`.github/workflows/ci.yml`, macOS runner) runs
`swift test --package-path Packages/KKitModules` (all module tests) and then
`xcodegen generate` + `xcodebuild build` for the app; check CI results to verify changes.

- Tests use Swift Testing. Fakes for every service and a ready-made `TestEnvironment`
  live in `KKitServicesTesting`.
- Signing: `Config/Signing.xcconfig` signs ad-hoc by default; a git-ignored
  `Config/Local.xcconfig` sets the developer's team. Never commit a team ID.
- Bundle ID is `com.kv.kkit`, log subsystem `com.kv.kkit`.
