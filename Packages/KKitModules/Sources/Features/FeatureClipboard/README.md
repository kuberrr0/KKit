# Clipboard History

Everything you copy, searchable, with a picker, a paste stack and snippets
(DESIGN.md §3.7).

- **Recording**: `ClipboardController` listens to `PasteboardService.changes()` (the service
  polls `changeCount` every 0.4 s, only while someone listens). `ClipboardFilter` decides
  what is saved: nothing marked `org.nspasteboard.ConcealedType`/`TransientType`/
  `AutoGeneratedType` (or password managers' own markers), nothing from ignored apps
  (password managers by default), and only the kinds turned on in Settings. KKit's own
  writes (pasting from history) aren't saved again.
- **Store**: `ClipboardStore` (actor) on the system SQLite via `StorageService.openDatabase`
  (`clipboard/history.sqlite`). Copying the same thing again moves it to the top (unique
  content hash). Search uses an FTS5 trigram index when SQLite has it, `LIKE` otherwise.
  Images are files in `clipboard/images/`. Pinned items are never trimmed.
- **Picker**: a Floating Bar mode (`clipboard.showHistory`, ⇧⌘V by default). ↵ pastes,
  ⌘↵ pastes as plain text, ⌘1…9 quick paste, ⌘P pin, ⌘C copy, ⌫/⌘⌫ delete, Tab cycles the
  filter (All, Pinned, Text, Links, Images, Files, Colours, Snippets), ⎋ clears, then goes back to search if the picker was opened from the bar
  (otherwise closes it); the ‹ in the header always goes back to search. Rows
  can be dragged out. `c ` in the Floating Bar searches history and snippets too.
- **Paste stack**: `clipboard.togglePasteStack` starts collecting; each copy joins the stack
  and `clipboard.pasteNext` pastes them oldest first. The stack shows in the Island.
- **Snippets**: name, keyword and text with `{date}`, `{time}`, `{datetime}`,
  `{date:FORMAT}`, `{clipboard}`, `{uuid}` (`SnippetExpander`); saved in `snippets.json`.
- **Pasting** sends ⌘V and needs Accessibility; without it, choosing an item only copies it.
- **⌘K actions** on history results: paste as plain text, copy, pin, delete, Add to Shelf
  (`ShelfServicing`) and Send to Note (`QuickNoteServicing`).
- Not yet: encrypting the history at rest, and the "Allow paste" prompt macOS may add.
